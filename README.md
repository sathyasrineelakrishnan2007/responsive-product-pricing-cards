
# Responsive Product Pricing Cards

## Description
A responsive pricing card website with monthly and yearly billing options.

## Features
- Monthly/Yearly billing toggle
- Hover effects using CSS transitions
- Popular plan badge
- Responsive design
- Interactive JavaScript functionality

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open index.html in a web browser.
3. Toggle between monthly and yearly pricing.

## Expected Outcome
To learn responsive UI design, CSS transitions, and JavaScript event handling.
